How it connects

One agent, one payment, five platforms in sequence.

A real request that only works because every platform reads the same event log.

01 · Wallet
Agent initiates payment
did:forge:agent_001 requests $50K USDC, net-30 terms — exceeds its current credit line.
02 · Agent Credit Bureau
Score checked
Score 75/100 reviewed; requires a credit extension past the R25K limit.
03 · Enterprise Treasury
CFO approves
Treasury manager extends the line to R100K — one click on the approval desk.
04 · Payments
Routed to Custody
Institutional-size transfer is routed to threshold signing, not the wallet.

Policy pass → approvals → threshold signature → broadcast.
06 · Ontology
