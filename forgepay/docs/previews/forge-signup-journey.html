03

Backend pipeline

What actually runs, in order, inside the signup API route — every step has to succeed for the account to activate.

  1. Validate with zod
    email().min(2).min(8) — malformed input returns 400 before touching the database.
  2. Check for existing email
    Duplicate → 409 Conflict, form shows “Email already registered.”
  3. Create tenant
    A new tenant row is inserted — named after the company, or the person if none given.
  4. Hash password
    bcrypt hash generated; the plaintext password is never stored or logged.
  5. Create user
    User row linked to the tenant.
  6. Generate JWT + set cookie
    Signed token embeds userId, email, tenantId; set as an HTTP-only auth cookie.
  7. Send verification email
    Async — contains a one-time verification link.
  8. Send onboarding email
    Async — the Day-1 welcome + quick-start sequence begins.
  9. 201 Created
    Response returns the user object; the browser redirects to /dashboard/payments.

06

The 14-day trial sequence

Activation isn't one event — it's a monitored sequence with a fallback path if the account goes quiet.

Day 0
Account created done
Verification + onboarding emails sent; dashboard active in sandbox.
Day 1–2
Quick-start & first test transaction tracked
Onboarding video + guided walkthrough; step completion tracked per funnel stage.
Day 3
CSM check-in conditional
If no test transaction yet, a reminder fires: “A CSM can help complete setup.”
Day 7
Progress check-in email
Usage summary + a nudge toward the next platform (Treasury or Credit Bureau) if Payments is active.
Day 13
Pre-close call
“Ready to go live?” — CSM offers to activate production access same-day.
Day 14
Trial expiry decision
Convert to paid, extend the trial, or the account moves to churn-risk monitoring in the Agent/CSM playbook.
07

Conversion — activated account

A converted account isn't just paid Payments — it's a single login across the full ontology, ready to expand into Treasury, Custody, Wallet, and Credit.

  • Billing activates
    Kill Bill starts the subscription; the trial banner disappears; production access unlocks.
  • Cross-sell surfaces
    As payment volume grows, the console highlights Treasury (netting ROI) and Agent Credit Bureau (for agent-heavy accounts) — same account, same data.
  • Retention monitoring begins
    The account now feeds the churn-signal pipeline (MRR decline, API inactivity, low usage) that the CSM playbook watches going forward.
