Agent Credit Flow

closed loop with bureau + custody
  1. 01Bureau requests extension for a scored agent.
  2. 02Treasury manager approves — line updated, custody authorized.
  3. 03FORGE Custody threshold-signs the draw from the enterprise account.
  4. 04Ontology records the draw; bureau tracks the receivable.
  5. 05On term, rule R-021 auto-sweeps principal + fee back.
  6. 06Bureau lifts the agent score; the line grows for next time.
