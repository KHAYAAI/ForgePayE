Key event flows

① Consumer / agent payment  — < $100K, wallet signs directly
consumer/agent→ forge-wallet⇒ wallet.transaction.confirmed unified-router⇒ Revenue Ontology⇒ agent-credit-bureau⇒ enterprise-treasury
② Institutional / agent-credit draw  — > $1M, threshold signing
Payments router→ forge-custody→ policy compliance-monitor→ approve CFO + CEO→ sign mpc-signer⇒ custody.signature.confirmed Ontology
③ Agent-credit closed loop  — the interconnection that is the moat
agent (wallet)needs > line → agent-credit-bureauextension req → enterprise-treasuryCFO approve → forge-custodysigns draw ⇒ Ontology→ score↑ → bigger line next time
